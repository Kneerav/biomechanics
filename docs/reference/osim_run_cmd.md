# Run OpenSim Command Line Tool

This function executes an OpenSim command line tool using
\`opensim-cmd\`.

## Usage

``` r
osim_run_cmd(opensim_path = "C:/\"OpenSim 4.5\"/bin", setup_file)
```

## Arguments

- opensim_path:

  A character string specifying the path to the OpenSim bin directory.

- setup_file:

  A character string specifying the path to the setup file (.xml) to be
  run with OpenSim.

## Value

The result of running the OpenSim command.
