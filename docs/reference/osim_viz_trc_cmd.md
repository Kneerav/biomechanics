# Visualize Marker Data in OpenSim

This function visualizes marker data in OpenSim using the
\`opensim-cmd\` tool.

## Usage

``` r
osim_viz_trc_cmd(
  opensim_path = "C:/\"OpenSim 4.5\"/bin",
  trc_file_path = "marker.trc"
)
```

## Arguments

- opensim_path:

  A character string specifying the path to the OpenSim bin directory.

- trc_file_path:

  A character string specifying the path to the TRC file containing the
  marker data (.trc).

## Value

The result of running the OpenSim command.
