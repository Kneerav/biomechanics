# Write a trc file

Write a trc file

## Usage

``` r
write.trc()
```

## Arguments

- x:

  dataframe containing data to write to trc. Should be in the same
  format produced from read.trc()

- unit:

  string contain unit of measurement in either "mm" or "m"

- filename:

  string identifying the filename to write to file. Must end in .trc

## Value

trc file of filename
