# Example Dataset: data_fukuchi_2018

An example dataset of joint angles from Fukuchi et al., 2018, released
under https://creativecommons.org/licenses/by/4.0/

## Usage

``` r
data_fukuchi_2018
```

## Format

A data frame with 1375620 rows and 6 variables:

- stride:

  Numeric stride

- participant:

  Character participant

- task:

  Character task

- variable:

  Character variable

- value:

  Numeric value

- gait_type:

  Character gait_type
