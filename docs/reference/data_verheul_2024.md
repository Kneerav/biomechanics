# Example Dataset: data_verheul_2024

An example dataset from Verheul et al., 2024, released under
https://www.apache.org/licenses/LICENSE-2.0

## Usage

``` r
data_verheul_2024
```

## Format

A data frame with 422685 rows and 7 variables:

- value:

  Numeric value

- variable:

  Character variable

- trial:

  Character trial

- participant:

  Character participant

- data_type:

  Character data_type

- leg:

  Character leg

- stance:

  Numeric variable

## Source

https://github.com/JasperVerheul/horizontal-deceleration-forces

## References

Verheul J, Harper D, Robinson MA. Forces experienced at different levels
of the musculoskeletal system during horizontal decelerations. J Sports
Sci. 2024 Dec;42(23):2242-2253. doi: 10.1080/02640414.2024.2428086.
