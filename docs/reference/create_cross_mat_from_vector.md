# Convert a Vector to a Cross Product Matrix

Given a 3D vector \`r\`, this function computes the corresponding cross
product matrix.

## Usage

``` r
create_cross_mat_from_vector(r)
```

## Arguments

- r:

  A numeric vector of length 3, representing the 3D vector.

## Value

A 3x3 numeric matrix representing the cross product matrix of the input
vector.
